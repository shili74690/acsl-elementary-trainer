# ACSL Trainer (Elementary Division)

An interactive, single-file web application designed to help elementary students practice and master core concepts for **American Computer Science League (ACSL) Contest #1**.

## Topics Covered
* **Computer Number Systems:** Converting between Base 2 (Binary), Base 8 (Octal), Base 10 (Decimal), and Base 16 (Hexadecimal), plus binary arithmetic.
* **Prefix / Infix / Postfix Notation:** Evaluating and translating mathematical expressions across standard and Polish/Reverse Polish notations.
* **Boolean Algebra:** Evaluating logical expressions using `AND`, `OR`, `NOT`, and `XOR` operators and truth tables.
* **Graph Theory:** Identifying vertices, edges, paths, cycles, and simple undirected/directed graph properties.

## Features
* **Self-Paced Practice:** Instant feedback and step-by-step explanations to help students learn from mistakes.
* **Zero Setup Required:** Built entirely in vanilla HTML, CSS, and JavaScript—runs directly in any modern web browser without external dependencies or student logins.
* **Classroom Ready:** Accessible via GitHub Pages or as a standalone offline `.html` file.
